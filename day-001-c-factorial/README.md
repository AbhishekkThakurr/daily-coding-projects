# Day 1 (C) — Factorial of a Number

A small C program that reads a number and prints its factorial.

## Concepts used
- `for` loop
- `long long` for larger results
- Input and output with `scanf` and `printf`

## How to run
```bash
gcc factorial.c -o factorial
./factorial
```

## Sample run
```
Enter a non-negative number: 5
Factorial of 5 is 120
```
