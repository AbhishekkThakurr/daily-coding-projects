# Day 1 (Python) — Palindrome Checker

A small Python program that checks whether a word or phrase reads the same forwards and backwards.

## Concepts used
- String slicing with a step of -1 to reverse
- `lower()` and `replace()` for cleaning the input
- A function with a return value

## How to run
```bash
python3 palindrome.py
```

## Sample run
```
Enter a word or phrase: madam
"madam" is a palindrome.
```
