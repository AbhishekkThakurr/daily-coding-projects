# Profile Card (HTML/CSS)

A simple, centred profile card page: photo, name, role, short bio, skill
badges, and a link button. A first step toward building real web pages.

## Concepts

- HTML structure: `div`, `h1`, `p`, `ul`, `img`, `a`
- Linking an external stylesheet with `<link>`
- CSS flexbox for centring (`display: flex`, `justify-content`, `align-items`)
- Box model: `padding`, `border-radius`, `box-shadow`
- `:hover` state on the button

## How to run

Open `index.html` in any browser (double-click the file, or serve it with
`python3 -m http.server` and visit `http://localhost:8000`).

## Sample run

The page shows a white card on a light-grey background: a round profile
photo at the top, the name "Abhishek Kumar", the role "BTech CSE Student",
a one-line bio, four skill badges (Java, C, Python, SQL), and a blue
"View GitHub" button that opens the GitHub profile.
