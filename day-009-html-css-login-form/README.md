# Login Form (HTML/CSS)

A clean, centred login form page — the kind of form almost every website has.

## What it does

Shows a login card with username and password fields, a "Remember me" checkbox, a "Forgot password?" link, a Log In button, and a sign-up link. Pure HTML + CSS, no JavaScript.

## Concepts

- HTML forms: `<form>`, `<label>`, `<input>`, `<button>`
- Flexbox — centring the card on the page and laying out the remember/forgot row
- CSS `linear-gradient` background
- `box-shadow` and `border-radius` for the card look
- `:focus` and `:hover` states for inputs and the button
- `box-sizing: border-box` so padding doesn't break widths

## How to run

Open `index.html` in any browser. No build step, no server needed.

## Sample run

Open the page and you see a white card on a purple gradient background:

- Heading: "Welcome Back"
- Subtitle: "Please log in to your account"
- Username and password fields with placeholder text
- A Log In button that darkens on hover
